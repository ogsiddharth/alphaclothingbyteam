# 🐺 ALPHA CLOTHING BY TEAM

Welcome to the official repository of **Alpha Clothing**. We redefine streetwear with a minimalist dark aesthetic and premium quality apparel.

## 🚀 Live Demo
[Check out the live website here!](https://yourusername.github.io/alphaclothingbyteam/)

## ✨ Key Features
- **Modern UI:** High-contrast dark theme with neon accents for a premium feel.
- **Dynamic Product Grid:** Fully responsive, Flipkart-style 2-column layout for mobile users.
- **Smart Shopping:** - Real-time "Add to Cart" functionality.
  - Direct "Buy Now" checkout system.
- **WhatsApp Integration:** Instant order confirmation and cancellation requests sent directly to the owner.
- **User Dashboard:** Order history tracking with real-time status updates (Pending/Confirmed/Delivered).
- **Admin Panel:** Specialized dashboard to manage and update order statuses.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Grid & Flexbox), JavaScript (ES6)
- **Styling:** Main.css (Responsive Patch for Mobile Optimization)
- **UI Components:** [SweetAlert2](https://sweetalert2.github.io/) for professional notifications.
- **Icons:** [Remix Icon](https://remixicon.com/)

## 📂 Project Structure
- `index.html` - The main landing page.
- `user.html` - Customer profile and order history.
- `payment.html` - Professional checkout page.
- `admin.html` - Order management for the team.
- `data.js` - Centralized product database.
- `main.css` - Global styling and responsive patches.
